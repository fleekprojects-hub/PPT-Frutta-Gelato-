Tantangan Ekspansi B2B

Keterbatasan Jam Kerja Admin vs Permintaan Pesanan Mitra 24 Jam

01.

Pesan & PO Malam Hari Terbengkalai

Mitra Horeca (Resto, Kafe, Hotel) sering melakukan stock-opname dan mengirim Purchase Order (PO) pada pukul 22.00–02.00 dini hari saat outlet tutup. Karena admin offline, PO baru diproses esok siang dan berisiko memperlambat jadwal pengiriman gelato.

02.

Website Menjadi Sumber Leads Tanpa Kualifikasi

Website fruttagelato.com adalah sumber leads inbound terbesar. Ratusan prospek bertanya seputar cara menjadi mitra, minimum order, dan ketersediaan mesin gelato, namun belum ada AI kualifikasi 24/7 untuk menjaring calon mitra ber-intent tinggi ke tim sales.

03.

Aplikasi ERP Existing Belum Terkoneksi Chat

Frutta Gelato telah memiliki aplikasi internal mirip ERP dengan Open API yang siap menerima data, namun saat ini tim admin masih melakukan copy-paste manual dari chat WhatsApp ke sistem. Tidak ada sinkronisasi otomatis dua arah.

💡 Kunci Solusi Fleek: Bukan merombak sistem ERP Frutta Gelato, melainkan memasang AI Gateway Cerdas yang menghubungkan chat mitra ke API ERP & Grup Operasional secara otomatis. OPEN API INTEGRATION

Arsitektur Dua Agen Mandiri

Pemisahan Alur: AI Admin Sales (Inbound) & AI PO Operations (24/7)

PILAR 01 // SALES ADMIN TARGET: CALON MITRA BARU

AI Inbound Qualifier & Partnership Bot

Menangani calon mitra yang masuk dari Website, WhatsApp, dan DM. Berfungsi menjawab Q&A dengan gaya komunikasi brand, membaca intent, dan melakukan kualifikasi data secara terstruktur.

  • ⚡ Coverage 24/7 Multi-Channel: Respons instan Website Chat, WhatsApp, & Instagram DM.
  • ⚡ Intent Memory: Mengenali apakah pengirim adalah New Lead atau Mitra Existing.
  • ⚡ Lead Qualifying: Menanyakan kota, konsep outlet (kafe/resto), dan estimasi kebutuhan tub.
  • ⚡ Sales Handover Escalation: Karena kemitraan bernilai tinggi tidak bisa di-close di chat, AI mengeskalasi lead qualified lengkap dengan ringkasan profil ke Tim Sales.
PILAR 02 // OPERATIONS ENGINE TARGET: MITRA EXISTING & HORECA

AI PO Capture, Doc Gen & ERP Gateway

Menangkap Purchase Order (PO) yang dikirim mitra existing di luar jam kerja. Mengurai rincian rasa/tub, meminta konfirmasi komitmen "Ya/Tidak", mencatat ke ERP, dan meneruskan ke Grup Operasional.

  • ⚡ Night-Shift Order Capture: Siap 24 jam menangani order malam hari tanpa admin jaga.
  • ⚡ Explicit Confirmation ("Ya/Tidak"): Menghindari salah order dengan meminta konfirmasi sebelum submit.
  • ⚡ Signed PO Document Generator: Men-generate dokumen PO berstempel digital resmi Frutta.
  • ⚡ Open API ERP Sync & Group Dispatch: Kirim payload ke sistem internal dan broadcast ke Grup WA Operasional agar pagi hari langsung dipersiapkan.
🎯 Arsitektur Praktis Klien: Frutta Gelato hanya menggunakan 1 Nomor WhatsApp Resmi. AI secara otomatis merouting: nomor baru diarahkan ke Workflow Sales, nomor mitra terdaftar diarahkan ke Workflow PO Malam Hari. SINGLE NUMBER ROUTING

Penerbitan PO Bertanda Tangan Digital & Batasan Non-Payment

Standar Integritas Dokumen PO Otomatis

Setiap kali mitra menyelesaikan konfirmasi pesanan di luar jam kerja, Fleek Intelligent Core secara instan meng-generate salinan dokumen PDF resmi yang mengikat kedua belah pihak:

  • 📑 Nomor PO Unik Otomatis: Terbit berurutan sinkron dengan penomoran ERP internal Frutta.
  • 🏷️ Standarisasi SKU & Rasa: Mencegah kesalahan ketik (misal: "Pistachio 5L" langsung di-mapping ke SKU PST-5L).
  • 🛡️ Timestamp Digital & Delivery Token: Dilengkapi kode verifikasi unik untuk supir/kurir saat serah terima di outlet mitra.
  • 🔒 Strict Non-Payment Guardrail: Sesuai permintaan eksplisit klien, sistem TIDAK memproses transaksi pembayaran uang. Pembayaran tetap mengikuti termin manual / transfer bank existing.

IT Readiness Gate • Prasyarat Integrasi ERP

Batasan Sistem: Fase 1 (Core MVP) vs Add-on Direct API ERP

Garis Batas Rilis Sistem
🟢 FASE 1: CORE MVP (100% MANDIRI) ZERO IT DEPENDENCY

Berjalan mandiri via WhatsApp Gateway Resmi + Dual AI Engine + Notifikasi Real-time ke Grup WA Operasional Frutta Bali + Fleek Database (Spreadsheet/Supabase) + Signed PDF PO Generator. Dijamin go-live cepat tanpa menunggu kesiapan server internal.

⚙️ FASE 1.5: DIRECT API ERP SYNC ADD-ON SETUP FEE

Sambungan langsung dua arah ke database ERP internal Frutta Gelato. Memerlukan penyesuaian khusus dan uji coba sandbox bersama tim IT Frutta.

4 Kebutuhan Teknis dari Tim IT Frutta (Checklist)
IT DISCOVERY GATE
1. API Endpoint URL (Sandbox / Staging)
Base URL endpoint staging yang dapat dijangkau Fleek Automation Core (contoh: POST /api/v1/orders/po-capture).
2. Token Key / API Key / Bearer Auth
Kredensial autentikasi header aktif dengan hak akses write/create order ke database internal Frutta.
3. JSON Payload Contract & Response Schema
Dokumentasi struktur field data pesanan (Swagger, Postman Collection, atau cURL sample) agar pemetaan SKU, Qty, dan Tanggal Kirim 100% presisi.
4. Webhook / Callback URL (Opsional)
Endpoint penerima sinyal status order dari gudang (IN_PREPARATION, IN_DELIVERY, COMPLETED).
🛡️ Klausul Jaminan Fleek: Jika tim IT Frutta memerlukan waktu untuk menyiapkan API/Endpoint, Fase 1 TETAP BERJALAN 100% GO-LIVE via Fleek DB & Grup WA Operasional tanpa menunda jadwal peluncuran! SAFETY FALLBACK
